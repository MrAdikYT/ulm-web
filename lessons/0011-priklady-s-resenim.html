Skolemova klauzulární forma

1. ∀x(∃y P(x, y) ⊃ ∀z Q(x, z))

Řešení 
k4: ∀x(¬∃y P(x, y) ∨ ∀z Q(x, z))
k5: ∀x(∀y ¬P(x, y) ∨ ∀z Q(x, z))
k6: ∀x∀y∀z(¬P(x, y) ∨ Q(x, z))
k7: žádné ∃ → nic ke Skolemizaci
klauzule:  ¬P(x, y) ∨ Q(x, z)

∃y nalevo od ⊃ se negací změnilo na ∀y. Proto žádná funkce.

2. ¬∀x∃y(P(x) ⊃ Q(y))

Řešení 
k4: ¬∀x∃y(¬P(x) ∨ Q(y))
k5: ∃x∀y ¬(¬P(x) ∨ Q(y))  =  ∃x∀y(P(x) ∧ ¬Q(y))
k7: x → a
klauzule:  P(a)   a   ¬Q(y)

3. ∀x∃y(P(x, y) ∨ ∃z(Q(z) ∧ ¬R(x, z)))

Řešení 
k6: ∀x∃y∃z(P(x, y) ∨ (Q(z) ∧ ¬R(x, z)))
k7: y → f(x), z → g(x)       (obě mají před sebou jen ∀x)
    P(x, f(x)) ∨ (Q(g(x)) ∧ ¬R(x, g(x)))
k9: (P(x, f(x)) ∨ Q(g(x))) ∧ (P(x, f(x)) ∨ ¬R(x, g(x)))
klauzule:  P(x, f(x)) ∨ Q(g(x))
           P(x, f(x)) ∨ ¬R(x, g(x))

Unifikace

4. P(x, f(y), y) a P(g(z), f(a), z)

Řešení 
x proti g(z)    → x/g(z)
f(y) proti f(a) → dovnitř: y/a
y(= a) proti z  → z/a       (a tím x = g(a))
σ = {x/g(a), y/a, z/a}
oba:  P(g(a), f(a), a)

5. Q(f(x), x, b) a Q(y, a, y)

Řešení 
f(x) proti y → y/f(x)
x proti a    → x/a     (y je teď f(a))
b proti y = f(a) → konstanta proti funkci → NEJDE

Rezoluce sporem

6. Každý muž (M) je smrtelný (Sm). Sokrates (s) je muž. ⟶ Někdo je smrtelný.

Řešení 
¬Z: ¬∃x Sm(x) = ∀x ¬Sm(x)
1. ¬M(x) ∨ Sm(x)
2. M(s)
3. ¬Sm(y)
4. Sm(s)     1 + 2, x/s
5. #         3 + 4, y/s       → platný

Tady existence vyplývá, protože Sokrates je konkrétní muž (konstanta s v předpokladu).

7. Každý student (S) čte (Č) nějakou knihu (K). Petr (p) je student. ⟶ Existuje kniha.

Řešení 
P1: ∀x(S(x) ⊃ ∃y(K(y) ∧ Č(x, y)))
¬Z: ¬∃y K(y) = ∀y ¬K(y)
1. ¬S(x) ∨ K(f(x))
2. ¬S(x) ∨ Č(x, f(x))
3. S(p)
4. ¬K(y)
5. K(f(p))   1 + 3, x/p
6. #         4 + 5, y/f(p)    → platný

8. Když Adam (a) má rád (R) všechny, má rád i Petra (p). Ověř, zda je logicky platná formule ∀x R(a, x) ⊃ R(a, p).

Řešení 
Neguji CELOU formuli (ověřuji platnost, ne úsudek):
¬(∀x R(a, x) ⊃ R(a, p)) = ∀x R(a, x) ∧ ¬R(a, p)
1. R(a, x)
2. ¬R(a, p)
3. #         1 + 2, x/p       → formule je logicky platná

9. Všichni ptáci (P) létají (L). Tučňák (t) nelétá. ⟶ Tučňák není pták. A potom: ⟶ Někdo je pták.

Řešení 
Závěr „Tučňák není pták“:     ¬Z: P(t)
1. ¬P(x) ∨ L(x)
2. ¬L(t)
3. P(t)
4. L(t)      1 + 3, x/t
5. #         2 + 4            → platný

Závěr „Někdo je pták“:        ¬Z: ∀y ¬P(y)
1. ¬P(x) ∨ L(x)
2. ¬L(t)
3. ¬P(y)
Žádné kladné P → # nevyjde   → neplatný

Druhý je past: ∀ předpoklad netvrdí, že nějaký pták existuje.

11. Všichni hráči (H) jsou sportovci (S). Žádný šachista (Š) není hráč. ⟶ Žádný šachista není sportovec.

Řešení

Š∩S mimo H (modré tečky vpravo dole) není šedé → může tam někdo být → neplatný.

Formalizace

12. Zapiš: a) Jen ten, kdo se učí (U), projde (P). b) Nikdo není dokonalý (D). c) Každý má někoho rád. d) Někoho mají rádi všichni.

Řešení 
a) ∀x(P(x) ⊃ U(x))         „jen“ otáčí směr
b) ¬∃x D(x)  =  ∀x ¬D(x)
c) ∀x∃y R(x, y)
d) ∃y∀x R(x, y)            pořadí kvantifikátorů mění význam!
